          TECHNICAL SPECIFICATIONS
          
Frequently asked questions

        


        

          

            
              Does AutoPatch send customer PII or financial numbers to Gemini/Groq?
              +
            
            

              
Never. Before any external model call, src/healer/sanitizer.ts strips all raw values and replaces them with structural value-class tokens (string:email_like, number:float, number:epoch_like). Only keys and value types leave the proxy.

            

          


          

            
              How does AutoPatch prevent mixing up data_id and user_id?
              +
            
            

              
AutoPatch enforces Entity Domain Disambiguation (separating user/customer paths from order/record/payment paths) plus a strict Gate 5 1-to-1 Source Path Exclusivity lock. Two required target fields can never map to the same source path; if a required ID is missing, AutoPatch fails closed with HTTP 502.

            

          


          

            
              What happens after the first cold AI heal?
              +
            
            

              
Once verified by all 5 safety gates, the mapping rule is keyed by the SHA-1 structural fingerprint of the payload and cached in memory. Every subsequent request with that shape is healed deterministically in 0.14 ms with zero AI calls.
