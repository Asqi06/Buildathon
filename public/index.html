Architecture Q&A

Questions, answered clearly

What if a payload has both data_id and user_id?+
AutoPatch uses Entity-Domain Disambiguation (separating record/order/transaction IDs from user/customer IDs) plus Gate 5 1-to-1 Source Path Exclusivity so two target fields can never map from the same source path. If a required ID is deleted, Gate 5 returns HTTP 502 instead of corrupting foreign keys.
Does AutoPatch send customer PII or financial numbers to Gemini?+
Never. src/healer/sanitizer.ts replaces 100% of raw values with structural tokens (string:email_like, number:float, number:epoch_like) in local memory before any model call.
What happens if 200 concurrent requests hit a cold drifted route at once?+
Single-Flight Promise Deduplication coalesces all 200 concurrent misses into a single Gemini inference call, caches the 5-Gate verified rule, and returns HTTP 200 OK to all 200 requests simultaneously.
